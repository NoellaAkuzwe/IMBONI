# Adding and Subtracting Fractions

## Fractions with the same denominator

A fraction has a numerator (the top number) and a denominator (the bottom number). The denominator tells us how many equal parts the whole is split into. When two fractions have the same denominator, we add the numerators and keep the denominator the same:

1/4 + 2/4 = 3/4

The parts are the same size, so we are only counting how many parts we have altogether.

## Fractions with different denominators

To add fractions with different denominators, first rewrite them as equivalent fractions with a common denominator. The lowest common denominator is the smallest number that both denominators divide into. For example, to add one half and one third, use the common denominator 6:

1/2 + 1/3 = 3/6 + 2/6 = 5/6

## Subtracting fractions

Subtraction works the same way: make the denominators the same, then subtract the numerators. For example, 3/4 - 1/2 = 3/4 - 2/4 = 1/4.

## Common mistakes

A common mistake is to add the denominators as well as the numerators, for example writing 1/2 + 1/3 = 2/5. Using fraction strips or pizza diagrams helps students see why this answer is too small.
